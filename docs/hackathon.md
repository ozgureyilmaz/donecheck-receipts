# hackathon

Receipts was built for the indie developer track of the [Meta Global AI Developer Hackathon](https://cerebralvalley.ai/e/meta-ai-developer-hackathon). It audits completion claims on a local mock airline using browser recordings, Muse Spark 1.3, deterministic checks, SAM 3.1 evidence boxes, and an append-only SQLite event log.

The submission deadline was November 4, 2026 at 9:00 p.m. ET, which was November 5 at 05:00 in Istanbul. The live browser verification, false-done demo, and 18-episode live judge replay finished after that deadline. [Final status](status.md) · [Evaluation](../EVAL.md)
